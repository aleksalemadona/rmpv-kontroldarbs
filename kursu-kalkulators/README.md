Kursu kalkulators uz PHP, HTML, CSS
Tika izstrādāti 4 faili:
data.php - glabājas visi mainīgie dati

    ir izveidoti mainīgie:

    $kursi - kursi, kas tiek attēloti kalkulatorā
    $max_dalibnieku_skaits - maksimālais dalībnieku skaits, kas var piedalīties kursos
    $atlaide_no - no cik dalībniekiem ir atlaide
    $atlaide - atlaides apmērs procentos

functions.php - izpildās vajadzīgās funkcijas

    kursuSumma - aprēķina kursu kopējās izmaksas

index.php attēlo programmas lapu
style.css izveido programmas dizainu
